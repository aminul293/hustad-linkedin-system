# Front end

There is no framework here and no build step. The page is generated by `pipeline/build_desk.py`,
which emits one self-contained HTML document: markup, styles and script inline, the send queue
embedded as JSON, no external dependencies except Google Fonts.

That choice was deliberate. The page has to work as a Claude artifact, as a static file on any host,
and from `file://` on a laptop with no network. A bundler would have bought nothing and cost all
three.

## Where things are, inside build_desk.py

| Part | What to look for |
|---|---|
| Styles | the `<style>` block; the palette is CSS custom properties on bare `:root`, redefined under `prefers-color-scheme` and again under `[data-theme]` so all three theme states resolve |
| Markup | the static shell; every row is rendered by JS from the embedded queue |
| Row rendering | `rowHtml()` |
| State | `state.entries` (`TARGETID|TOUCH`) plus `state.content` (calendar ids), both persisted to `localStorage`, merged per key by newest `ts` |
| The five tabs | the `tabrail` nav and `.pane` wrappers; Outreach is the desk, the other four panes are rendered server side by `pipeline/studio.py` |
| Asset export | `.dlpng` / `.dlsvg` serialize the inline SVG (canvas at 2x for PNG); `.prslides` clones slides into `#printhost` and prints, one slide per 4:5 page |
| Log export | `logRows()`, `toCsv()`, `toTsv()` |
| Host capabilities | the bottom of the script: artifact self-publish and file download, both optional |

## Two things to know before changing it

**The tab a row is showing when it is ticked decides what gets logged** as the opener type. That is
how the Friday review compares planned copy against shared-history and storm-trigger openers, which
is the experiment that justifies the daily research job. Do not break the link between the visible
tab and `setEnt(..., {opener})`.

**The page contains a base64 copy of its own template** so it can republish itself inside the Claude
host. `build_desk.py` asserts the quine round-trips; if you edit the template and that assertion
fires, the substitution tokens have drifted. Outside that host the whole mechanism is inert and
localStorage carries the log.

## Rebuilding while you work

make sample && make serve     # synthetic data, http://localhost:8000
